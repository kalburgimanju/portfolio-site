# Google Drive Setup

Your books are available in Google Drive:
https://drive.google.com/drive/folders/1RfWRuJskPmsZJ_QddMdqLXJuXEWdBnWX?usp=drive_link

## Steps

1. Open the Drive folder above
2. For each book below, find the matching `book.pdf` file
3. Right-click the file → Share → &quot;Anyone with the link can view&quot;
4. Copy the share link and paste it into `driveLink` in `data/books.js`
